First playable build of the Metroid Prime PS Vita port (build 49).

**You need your own copy of the game.** These downloads contain no Nintendo game data.

### Install
1. Install `MetroidPrime.vpk` with VitaShell.
2. Unzip `MetroidPrime-data.zip` and copy its `ux0` folder to the root of your Vita's memory card (merge). This adds the button-prompt textures and the `rom` folder.
3. Put your Metroid Prime ISO (GameCube, USA Rev 2) in `ux0:data/MetroidPrime/rom/`.
4. Launch the game. If something goes wrong, the log is `ux0:data/MetroidPrime/error.log`.

### Status
- Fully playable with Vita controls (twin-stick aiming, shoulders for L/R).
- Performance is still being worked on: light rooms run about 14–30 fps, heavy rooms are slower.
- The LiveArea art is a placeholder.
